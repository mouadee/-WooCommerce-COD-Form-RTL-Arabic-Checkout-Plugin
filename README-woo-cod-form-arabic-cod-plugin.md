# 🚚 WooCommerce COD Form — RTL Arabic Checkout Plugin

A clean, fast, RTL-ready WooCommerce Cash on Delivery form plugin designed for Arabic stores, Moroccan e-commerce, and one-page product checkout experiences.

---

## ✨ Main Features

### 🧾 Frontend COD Order Form
- Arabic RTL form layout.
- Clean and responsive mobile design.
- Cairo font support.
- Customizable input fields.
- Quantity selector with `+ / -`.
- Live total amount update.
- Compact and clean total amount design.
- Product image, title, and price support.
- Works directly on WooCommerce product pages.

---

## 🎨 4 Frontend Form Templates

The plugin includes 4 different frontend form designs. Each template changes the real form appearance on the product page, not only the admin preview.

### 🇲🇦 Moroccan Market
A warm, direct, conversion-focused design for COD stores in Morocco.

### ⚡ Minimal Express
A clean and simple checkout style with less visual noise.

### 👗 Fashion Boutique
A softer premium style for clothes, beauty, and lifestyle products.

### 📱 Electronics Pro
A tech-style design suitable for gadgets and electronics.

The **حجم الحقول** setting uses pixels instead of fixed presets.

Example:
- `44px` = compact
- `52px` = balanced/default
- `60px` = large

Allowed range:
- Minimum: `34px`
- Maximum: `90px`

## 🎁 Offers & Bundles — العروض والباقات

The plugin supports a complete bundle offer system.

### Bundle Features
- Enable/disable bundles.
- Add 3 customizable bundle offers.
- Set title, quantity, price, badge text, and popular status.
- Choose the default selected bundle.
- Update quantity automatically when selecting a bundle.
- Update total amount automatically.
- Save selected bundle details in WooCommerce order meta.
- Apply bundle price server-side for better security.
- Optional free delivery text.
- Optional urgency text.

### Example Bundles
- `1 قطعة — 43 د.م`
- `2 قطع — 79 د.م — الأكثر طلباً`
- `3 قطع — 109 د.م — وفر 20 د.م`

## 🔧 Installation

1. Go to WordPress admin.
2. Open **Plugins → Add New**.
3. Click **Upload Plugin**.
4. Upload the ZIP file.
5. Click **Install Now**.
6. Activate the plugin.
7. Open the plugin settings page.
8. Configure your form, template, currency, bundles, and fields.

---

## ♻️ Updating the Plugin

Before updating:
1. Download a backup of your current plugin.
2. Upload the new ZIP.
3. Replace the old version if WordPress asks.
4. Clear cache if you use a caching plugin.
5. Test the form on mobile and desktop.
